# Logos dos clientes (seção Cases)

Salve cada logo aqui com o **id do projeto** como nome (os ids estão em `src/data/projects.ts`):

| Cliente              | Arquivo                  |
| -------------------- | ------------------------ |
| Tapa na Pantera      | `tapa-na-pantera.svg`    |
| Vitor Hugo Gomes     | `vitor-hugo-gomes.svg`   |
| Letícia Coutinho     | `leticia-coutinho.svg`   |
| Diagnosis Vet        | `diagnosis-vet.svg`      |
| Ana Carms Expedições | `ana-carms.svg`          |

Também aceita `.png` e `.webp`. O logo entra sozinho no lugar do nome em texto.

Para ficar bom:

- **Fundo transparente** (SVG ou PNG). O site deixa o logo numa cor só (escuro, e branco no
  hover), então um logo com fundo sólido vira um retângulo.
- Prefira a versão **horizontal** do logo, sem margens sobrando em volta.
